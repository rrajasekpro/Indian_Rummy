# Indian Rummy Score Tracker

A Progressive Web App (PWA) for tracking scores in Indian Rummy games.

## Features
- Track 2-8 players
- Customizable rounds (5-20 or unlimited)
- Automatic winner calculation
- Install as mobile app

## Use the App
Visit: https://rrajasekpro.github.io/Indian_Rummy

## Install on Mobile
- **iOS**: Open in Safari → Share → Add to Home Screen
- **Android**: Open in Chrome → Menu → Install App
